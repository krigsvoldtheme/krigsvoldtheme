# Krigsvold language snapshot

These files are an exact, pinned copy of the independent core repository's grammar, decisions and implementation manifest. `snapshot.json` identifies the source commit and SHA-256 hashes. Run `node scripts/sync-language.mjs /absolute/core/checkout FULL_COMMIT` to refresh deliberately. The website's installed npm core and Astro packages remain pinned independently; a candidate specification does not imply a package is released.
