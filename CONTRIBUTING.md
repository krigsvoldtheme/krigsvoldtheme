# Contributing

Preserve Krigsvold's paper, navy, ice, and bronze identity while improving its usefulness in real applications.

1. Edit `src/palettes.mjs`, `src/ports.mjs`, or the relevant application exporter.
2. Keep role names matched across Light and Dark. Source reference colors come from `references/krigsvold-source.css` and are distinct from adjustable application colors.
3. Run `npm run tokens`, `npm test`, and `npm run build`.
4. Run `npm run test:browser` after changes to the website or privacy controls.
5. Describe contrast changes, include application screenshots when relevant, and update the changelog.

Avoid adding independently sourced artwork without the necessary rights. Native application ports need installation instructions and validation in the target application before being described as visually verified.
